# Torrezs Film

Site de portfólio de audiovisual (casamentos e eventos) em Recife-PE.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie para a raiz do repositório: `index.html`, a pasta `assets` e o arquivo `.nojekyll`.
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main` e pasta `/ (root)`.
4. Aguarde um ou dois minutos e abra o endereço que o GitHub mostrar.

Não separe o `index.html` da pasta `assets`: o vídeo e as fotos ficam lá.
